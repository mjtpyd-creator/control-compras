# Control-Compras — Subir a GitHub / Render

## Archivos y carpetas a subir

- control-compras.xlsx              (libro, vacío o con datos)
- servidor.py                      (servidor web + API)
- requisitos.txt                    (dependencias Python)
- render.yaml                       (config Render)
- web/                              (app web: index.html, app.js, style.css, iconos)
- scripts/                          (registrar, prediccion, verificar, etc.)
- tickets/                          (carpetas entrada/ archivados/ — opcional si usas fotos)
- Abrir_Compras.bat                 (acceso directo en escritorio)
- reporte.html                      (reporte estático, opcional)

## Pasos
1. Creá repo en github.com/new
2. Subí esta carpeta completa por git o arrastrando al repo web
3. Si usás Render: conectá el repo y usa render.yaml que ya está en la carpeta

Nota: No subir `__pycache__`, `.pyc`, ni carpetas de caché del sistema.
